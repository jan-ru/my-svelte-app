# Classification crosswalk

The `/classification` page follows an SBI 2025 code to the NYU Stern (Damodaran) industries:

SBI 2025 → NACE Rev. 2.1 (same first four digits) → NACE Rev. 2 / SBI 2008 / ISIC Rev. 4 → ISIC Rev. 3.1 → NAICS 2002 (US) → SIC 1987 → Damodaran industry.

The data lives in `src/lib/data/crosswalk.json`, generated by `node scripts/build-crosswalk.mjs <input-dir>`. The input directory needs these files (download them manually; they are not committed):

| File | Source |
|---|---|
| `sbi2025_structuur.xlsx` | CBS, SBI 2025 structure (version 2026, Dutch and English) |
| `schakel_2025_2008.xlsx` | CBS, conversion table SBI 2025 to SBI 2008 (v2.0) |
| `isic4_isic31.txt` | UN Statistics Division, ISIC Rev. 4 to ISIC Rev. 3.1 |
| `isic31_naics2002_titles.txt` | UN Statistics Division, ISIC Rev. 3.1 to NAICS 2002 US (code pairs and titles) |
| `sic_naics2002.xls` | US Census Bureau, 1987 SIC to 2002 NAICS |
| `indname.xls` | NYU Stern, `pc/datasets/indname.xls` (about 22 MB, company-level list with SIC code and industry) |

Every hop is many-to-many. The last step counts companies per Damodaran industry over all SIC codes reached; it is a guide, not an official mapping. The source files state no licence terms on the pages consulted: check them before redistributing the generated JSON beyond this repository.

## Reverse direction

The same page also goes from a Damodaran industry to SBI 2025 classes. It starts from the SIC codes of the industry's companies and walks the chain backwards, splitting weight evenly at every one-to-many hop, so the shares add up to 100% of the companies that could be followed. Group codes in the company list that are not real SIC codes (for example 6020) are spread over the real codes in the same three-digit group.

## Known approximations

- NACE Rev. 2 to ISIC Rev. 4 does not use an official table. A NACE class is an ISIC class or a subdivision of one, so the build matches by exact code, then by the same three-digit group, then by the nearest ISIC code in the same division (the build prints how many of each).
- Companies whose SIC code is missing from the Census table (and has no siblings) cannot be followed; the page shows the share that could.

## Company list

`node scripts/build-companies.mjs <path-to-indname.xls>` writes `src/lib/data/companies.json` (about 3.4 MB, 1 MB gzipped): name, ticker, SIC code, industry, country and region for each of the 48,156 companies, with the repeated text stored once in lookup lists. The `/companies` page reads it on the server only. Rebuild it, together with the crosswalk, when NYU publishes a new `indname.xls`. NYU states no licence terms on the pages consulted; check them before redistributing the file beyond this repository.
