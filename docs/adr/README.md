# Design decisions

Each ADR states one decision, the alternatives that were ruled out, its consequences and, where there is one, an open challenge. The current design is the set of Accepted ADRs.

## How decisions change

- An ADR records a decision when it was made. A changed decision is a new ADR that says what it supersedes; the old one stays, with its status set to `Superseded by ADR-N`.
- Status is one of `Proposed`, `Accepted`, `Deprecated` or `Superseded by ADR-N`.
- An accepted ADR is edited in place only for its status, links, dated clarifications and factual corrections.
- Files are `docs/adr/NNNN-<slug>.md` with front matter (`status`, `date`, `decision-makers`), and this table lists every one with the same status as its file.

The ADRs 001 to 009 were written on 2026-11-01 from the code, `CLAUDE.md`, the specs in `docs/superpowers/specs/` and the PRs; their dates are the dates the decisions were made.
