# Home Page: Valuation Multiples Comparison Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the demo home page with a tool that compares NYU Stern valuation multiples as grouped bar charts, for 1-4 multiples, 1-4 regions and 1-4 industries, with all state in the URL.

**Architecture:** A SvelteKit `load` function reads the URL, fetches and caches only the needed NYU `.xls` workbooks on the server (SheetJS), reshapes the result for the chosen chart layout, and returns it. The page renders hand-written SVG bar charts and a GET form whose fields are the URL parameters. All logic lives in small pure modules covered by Vitest.

**Tech Stack:** SvelteKit 3, Svelte 5 (runes), Vite 8, TypeScript 6, Vitest, SheetJS (`xlsx` 0.20.3 from its CDN), `@sveltejs/adapter-vercel`, Node 24.

**Spec:** `docs/superpowers/specs/2026-10-24-home-page-design.md`

```ts
export type Family = 'vebitda' | 'pe' | 'pbv' | 'ps';
export type Role = 'multiples' | 'regions' | 'industries';

export interface Region {
	id: string;
	label: string;
	/** Appended to the family name to get the regional workbook name. */
	suffix: string;
}

export interface Multiple {
	id: string;
	label: string;
	family: Family;
	/** Column header text in the sheet (whitespace-normalised). */
	column: string;
	/** Header group the column must sit under, for two-level headers. */
	group?: string;
}

export const REGIONS: readonly Region[] = [
	{ id: 'us', label: 'US', suffix: '' },
	{ id: 'europe', label: 'Europe', suffix: 'Europe' },
	{ id: 'global', label: 'Global', suffix: 'Global' },
	{ id: 'japan', label: 'Japan', suffix: 'Japan' },
	{ id: 'india', label: 'India', suffix: 'India' },
	{ id: 'china', label: 'China', suffix: 'China' },
	{ id: 'emerging', label: 'Emerging Markets', suffix: 'emerg' },
	{ id: 'anz-canada', label: 'Australia, NZ and Canada', suffix: 'Rest' }
];

const POSITIVE_EBITDA = 'Only positive EBITDA firms';

export const MULTIPLES: readonly Multiple[] = [
	{ id: 'ev_ebitda', label: 'EV/EBITDA', family: 'vebitda', column: 'EV/EBITDA', group: POSITIVE_EBITDA },
	{ id: 'ev_ebit', label: 'EV/EBIT', family: 'vebitda', column: 'EV/EBIT', group: POSITIVE_EBITDA },
	{ id: 'pe_trailing', label: 'P/E (trailing)', family: 'pe', column: 'Trailing PE' },
	{ id: 'pe_forward', label: 'P/E (forward)', family: 'pe', column: 'Forward PE' },
	{ id: 'pe_current', label: 'P/E (current)', family: 'pe', column: 'Current PE' },
	{ id: 'pbv', label: 'P/B', family: 'pbv', column: 'PBV' },
	{ id: 'ev_ic', label: 'EV/Invested Capital', family: 'pbv', column: 'EV/ Invested Capital' },
	{ id: 'ps', label: 'P/S', family: 'ps', column: 'Price/Sales' },
	{ id: 'ev_sales', label: 'EV/Sales', family: 'ps', column: 'EV/Sales' }
];

const US_FILE: Record<Family, string> = {
	vebitda: 'vebitda',
	pe: 'pedata',
	pbv: 'pbvdata',
	ps: 'psdata'
};

const BASE_URL = 'https://pages.stern.nyu.edu/~adamodar/pc/datasets/';

export const multipleById = (id: string): Multiple | undefined => MULTIPLES.find((m) => m.id === id);
export const regionById = (id: string): Region | undefined => REGIONS.find((r) => r.id === id);

export function workbookName(family: Family, regionId: string): string {
	const region = regionById(regionId);
	if (!region) throw new Error(`Unknown region: ${regionId}`);
	return region.id === 'us' ? US_FILE[family] : `${family}${region.suffix}`;
}

export const workbookUrl = (family: Family, regionId: string): string =>
	`${BASE_URL}${workbookName(family, regionId)}.xls`;
```

Rules (from the spec): an absent key means "use the default"; a present key with only empty values (`m=`) means the visitor cleared the list; a key whose values are all unknown is treated as absent; duplicates removed; at most 4 kept; layout must be a permutation of the three roles or the default applies.

```ts
import { MAX_SELECTION, MULTIPLES, REGIONS, type Role } from './catalog';

export interface Selection {
	multiples: string[];
	regions: string[];
	industries: string[];
}

export interface Layout {
	panels: Role;
	x: Role;
	color: Role;
}

export interface ViewParams {
	selection: Selection;
	layout: Layout;
}

export const DEFAULT_SELECTION: Selection = {
	multiples: ['ev_ebitda', 'pe_trailing'],
	regions: ['us', 'europe'],
	industries: ['Software (System & Application)', 'Retail (General)', 'Total Market']
};

export const DEFAULT_LAYOUT: Layout = { panels: 'multiples', x: 'industries', color: 'regions' };

const ROLES: readonly Role[] = ['multiples', 'regions', 'industries'];
const MULTIPLE_IDS = new Set(MULTIPLES.map((m) => m.id));
const REGION_IDS = new Set(REGIONS.map((r) => r.id));
const MAX_NAME_LENGTH = 100;

function readList(
	sp: URLSearchParams,
	key: string,
	isValid: (value: string) => boolean,
	fallback: readonly string[]
): string[] {
	if (!sp.has(key)) return [...fallback];
	const raw = sp.getAll(key).filter((v) => v !== '');
	const kept = [...new Set(raw)].filter(isValid);
	if (kept.length === 0 && raw.length > 0) return [...fallback];
	return kept.slice(0, MAX_SELECTION);
}

function readLayout(sp: URLSearchParams): Layout {
	const panels = sp.get('p');
	const x = sp.get('x');
	const color = sp.get('c');
	const roles = [panels, x, color];
	const valid =
		roles.every((r): r is Role => ROLES.includes(r as Role)) && new Set(roles).size === 3;
	return valid ? { panels: panels as Role, x: x as Role, color: color as Role } : { ...DEFAULT_LAYOUT };
}

export function parseParams(sp: URLSearchParams): ViewParams {
	return {
		selection: {
			multiples: readList(sp, 'm', (v) => MULTIPLE_IDS.has(v), DEFAULT_SELECTION.multiples),
			regions: readList(sp, 'r', (v) => REGION_IDS.has(v), DEFAULT_SELECTION.regions),
			industries: readList(sp, 'i', (v) => v.length <= MAX_NAME_LENGTH, DEFAULT_SELECTION.industries)
		},
		layout: readLayout(sp)
	};
}

export function toSearchParams({ selection, layout }: ViewParams): URLSearchParams {
	const sp = new URLSearchParams();
	const write = (key: string, values: string[]) => {
		if (values.length === 0) sp.append(key, '');
		for (const v of values) sp.append(key, v);
	};
	write('m', selection.multiples);
	write('r', selection.regions);
	write('i', selection.industries);
	sp.set('p', layout.panels);
	sp.set('x', layout.x);
	sp.set('c', layout.color);
	return sp;
}

/** Assign `dim` to `key`; whichever role had `dim` takes over the old value. */
export function applyRole(layout: Layout, key: keyof Layout, dim: Role): Layout {
	const next: Layout = { ...layout, [key]: dim };
	const other = (Object.keys(layout) as (keyof Layout)[]).find(
		(k) => k !== key && layout[k] === dim
	);
	if (other) next[other] = layout[key];
	return next;
}
```

```ts
/** Colour-blind-safe palette (Okabe-Ito), one colour per series position. */
export const PALETTE: readonly string[] = ['#0072B2', '#E69F00', '#009E73', '#CC79A7'];

/** Bars based on fewer firms than this are drawn hatched. */
export const LOW_FIRMS_THRESHOLD = 10;

export function formatMultiple(value: number | null): string {
	return value === null ? 'n/a' : `${value.toFixed(1)}x`;
}

/** Round tick values covering [min, max]; the range always includes 0. */
export function niceTicks(
	min: number,
	max: number,
	count = 5
): { ticks: number[]; min: number; max: number } {
	const lo = Math.min(0, min);
	const hi = Math.max(0, max);
	if (hi === lo) return { ticks: [0, 1], min: 0, max: 1 };

	const raw = (hi - lo) / (count - 1);
	const exp = Math.floor(Math.log10(raw));
	const fraction = raw / 10 ** exp;
	const step = (fraction <= 1 ? 1 : fraction <= 2 ? 2 : fraction <= 5 ? 5 : 10) * 10 ** exp;

	const niceMin = Math.floor(lo / step) * step;
	const niceMax = Math.ceil(hi / step) * step;
	const n = Math.round((niceMax - niceMin) / step);
	const ticks = Array.from({ length: n + 1 }, (_, i) => Number((niceMin + i * step).toFixed(10)));
	return { ticks, min: ticks[0], max: ticks[ticks.length - 1] };
}
```

```ts
import * as XLSX from 'xlsx';
import { workbookUrl, type Family } from '../catalog';

const SHEET = 'Industry Averages';
export const FETCH_TIMEOUT_MS = 10_000;

export interface Cell {
	value: number | null;
	firms: number | null;
}

export interface WorkbookRow {
	industry: string;
	firms: number | null;
	/** values[i] is the numeric content of column i (null if blank or NA). */
	values: (number | null)[];
}

export interface WorkbookData {
	/** ISO date (YYYY-MM-DD) from the "Date updated" cell, if present. */
	updated: string | null;
	header: string[];
	/** The header group above each column, '' when there is none. */
	groups: string[];
	rows: WorkbookRow[];
}

export class MissingColumnError extends Error {}

const normalise = (v: unknown): string => (typeof v === 'string' ? v.replace(/\s+/g, ' ').trim() : '');
const toNumber = (v: unknown): number | null => (typeof v === 'number' && Number.isFinite(v) ? v : null);

/** Some NYU files call the market-wide row "Grand Total" instead of "Total Market". */
const canonicalIndustry = (name: string): string => (name === 'Grand Total' ? 'Total Market' : name);

function serialToIso(serial: number): string {
	return new Date(Date.UTC(1899, 11, 30) + Math.round(serial) * 86_400_000).toISOString().slice(0, 10);
}

export function parseWorkbook(data: Uint8Array): WorkbookData {
	const workbook = XLSX.read(data, { type: 'array' });
	const sheet = workbook.Sheets[SHEET];
	if (!sheet) throw new Error(`Sheet "${SHEET}" not found`);

	const rows = XLSX.utils.sheet_to_json<unknown[]>(sheet, { header: 1, defval: null });
	const headerIndex = rows.findIndex((r) => normalise(r[0]) === 'Industry Name');
	if (headerIndex === -1) throw new Error('Header row "Industry Name" not found');

	const dateRow = rows.slice(0, headerIndex).find((r) => normalise(r[0]) === 'Date updated:');
	const serial = dateRow ? toNumber(dateRow[1]) : null;

	const header = rows[headerIndex].map(normalise);

	// A group row sits directly above the header: first cell empty, some text further right.
	const above = headerIndex > 0 ? rows[headerIndex - 1] : null;
	const hasGroups =
		above !== null &&
		above[0] == null &&
		above.some((c) => typeof c === 'string' && c.trim() !== '');
	let current = '';
	const groups = header.map((_, i) => {
		if (hasGroups) {
			const label = normalise(above[i]);
			if (label) current = label;
		}
		return current;
	});

	const dataRows: WorkbookRow[] = [];
	for (const r of rows.slice(headerIndex + 1)) {
		const industry = canonicalIndustry(normalise(r[0]));
		if (!industry) continue;
		dataRows.push({ industry, firms: toNumber(r[1]), values: header.map((_, i) => toNumber(r[i])) });
	}

	return { updated: serial === null ? null : serialToIso(serial), header, groups, rows: dataRows };
}

/** One column of the workbook as industry -> cell. Throws MissingColumnError if absent. */
export function pickColumn(wb: WorkbookData, column: string, group?: string): Map<string, Cell> {
	const wanted = normalise(column);
	const wantedGroup = group === undefined ? undefined : normalise(group);
	const index = wb.header.findIndex(
		(h, i) => i >= 2 && h === wanted && (wantedGroup === undefined || wb.groups[i] === wantedGroup)
	);
	if (index === -1) {
		throw new MissingColumnError(`Column "${column}"${group ? ` in group "${group}"` : ''} not found`);
	}
	return new Map(wb.rows.map((r) => [r.industry, { value: r.values[index], firms: r.firms }]));
}

export async function fetchWorkbook(
	family: Family,
	regionId: string,
	fetchFn: typeof fetch = fetch
): Promise<WorkbookData> {
	const url = workbookUrl(family, regionId);
	const response = await fetchFn(url, { signal: AbortSignal.timeout(FETCH_TIMEOUT_MS) });
	if (!response.ok) throw new Error(`NYU returned ${response.status} for ${url}`);
	return parseWorkbook(new Uint8Array(await response.arrayBuffer()));
}
```

```ts
export interface Cache<T> {
	get(key: string, load: () => Promise<T>): Promise<T>;
}

export function createCache<T>(options: { ttlMs: number; now?: () => number }): Cache<T> {
	const now = options.now ?? Date.now;
	const store = new Map<string, { value: T; expires: number }>();
	const inflight = new Map<string, Promise<T>>();

	return {
		async get(key, load) {
			const hit = store.get(key);
			if (hit && hit.expires > now()) return hit.value;

			const pending = inflight.get(key);
			if (pending) return pending;

			const promise = load()
				.then((value) => {
					store.set(key, { value, expires: now() + options.ttlMs });
					return value;
				})
				.catch((error: unknown) => {
					if (hit) return hit.value; // serve the stale copy rather than fail
					throw error;
				})
				.finally(() => inflight.delete(key));

			inflight.set(key, promise);
			return promise;
		}
	};
}
```

```ts
import type { Selection } from '../params';
import { createCache } from './cache';
import { MissingColumnError, fetchWorkbook, pickColumn, type Cell, type WorkbookData } from './nyu';

export interface Comparison {

	updated: string | null;
	/** cells[multipleId][regionId][industry] */
	cells: Record<string, Record<string, Record<string, Cell>>>;

}

export type WorkbookLoader = (family: Family, regionId: string) => Promise<WorkbookData>;

const cache = createCache<WorkbookData>({ ttlMs: 24 * 60 * 60 * 1000 });

export const loadWorkbook: WorkbookLoader = (family, regionId) =>
	cache.get(`${family}:${regionId}`, () => fetchWorkbook(family, regionId));

const messageOf = (error: unknown): string => (error instanceof Error ? error.message : String(error));

export async function getComparison(
	selection: Selection,
	load: WorkbookLoader = loadWorkbook
): Promise<Comparison> {
	const multiples = MULTIPLES.filter((m) => selection.multiples.includes(m.id));

	const wanted = new Map<string, { family: Family; regionId: string }>();
	for (const m of multiples) {
		for (const regionId of selection.regions) {
			wanted.set(`${m.family}:${regionId}`, { family: m.family, regionId });
		}
	}

	const loaded = new Map<string, WorkbookData | Error>();
	await Promise.all(
		[...wanted].map(async ([key, { family, regionId }]) => {
			try {
				loaded.set(key, await load(family, regionId));
			} catch (error) {
				loaded.set(key, error instanceof Error ? error : new Error(String(error)));
			}
		})
	);

	const comparison: Comparison = { updated: null, cells: {}, errors: {} };

	for (const m of multiples) {
		comparison.cells[m.id] = {};
		for (const regionId of selection.regions) {
			const workbook = loaded.get(`${m.family}:${regionId}`);
			const errorKey = `${m.id}:${regionId}`;

			if (workbook instanceof Error || workbook === undefined) {
				comparison.errors[errorKey] = `Data unavailable: ${workbook ? messageOf(workbook) : 'not loaded'}`;
				continue;
			}

			try {
				const column = pickColumn(workbook, m.column, m.group);
				comparison.cells[m.id][regionId] = Object.fromEntries(
					selection.industries.map((name) => [name, column.get(name) ?? { value: null, firms: null }])
				);
				if (workbook.updated && (!comparison.updated || workbook.updated > comparison.updated)) {
					comparison.updated = workbook.updated;
				}
			} catch (error) {
				if (!(error instanceof MissingColumnError)) throw error;
				comparison.errors[errorKey] = `Data unavailable: ${error.message}`;
			}
		}
	}

	return comparison;
}

/** Industry names, taken from the US P/E workbook (all workbooks share the same names). */
export async function getIndustries(load: WorkbookLoader = loadWorkbook): Promise<string[]> {
	const workbook = await load('pe', 'us');
	return workbook.rows.map((r) => r.industry);
}
```

```ts
import { multipleById, regionById, type Role } from './catalog';
import type { Layout, Selection } from './params';
import type { Comparison } from './server/compare';

export interface Bar {
	value: number | null;
	firms: number | null;
	error?: string;
}

export interface PanelModel {
	key: string;
	title: string;
	categories: string[];
	series: string[];
	/** bars[categoryIndex][seriesIndex] */
	bars: Bar[][];
}

export interface LayoutModel {
	/** Shared legend: the labels of the colour dimension. */
	series: string[];
	panels: PanelModel[];
}

interface Item {
	id: string;
	label: string;
}

function itemsFor(role: Role, selection: Selection): Item[] {
	switch (role) {
		case 'multiples':
			return selection.multiples.map((id) => ({ id, label: multipleById(id)?.label ?? id }));
		case 'regions':
			return selection.regions.map((id) => ({ id, label: regionById(id)?.label ?? id }));
		case 'industries':
			return selection.industries.map((name) => ({ id: name, label: name }));
	}
}

export function buildLayout(selection: Selection, layout: Layout, comparison: Comparison): LayoutModel {
	const panelItems = itemsFor(layout.panels, selection);
	const xItems = itemsFor(layout.x, selection);
	const colorItems = itemsFor(layout.color, selection);

	const panels = panelItems.map((panel) => ({
		key: panel.id,
		title: panel.label,
		categories: xItems.map((x) => x.label),
		series: colorItems.map((c) => c.label),
		bars: xItems.map((x) =>
			colorItems.map((color): Bar => {
				const at: Record<Role, string> = { multiples: '', regions: '', industries: '' };
				at[layout.panels] = panel.id;
				at[layout.x] = x.id;
				at[layout.color] = color.id;

				const error = comparison.errors[`${at.multiples}:${at.regions}`];
				if (error) return { value: null, firms: null, error };

				const cell = comparison.cells[at.multiples]?.[at.regions]?.[at.industries];
				return { value: cell?.value ?? null, firms: cell?.firms ?? null };
			})
		)
	}));

	return { series: colorItems.map((c) => c.label), panels };
}
```

```ts
import { buildLayout } from '$lib/layout';
import { DEFAULT_SELECTION, parseParams } from '$lib/params';
import { getComparison, getIndustries } from '$lib/server/compare';
import type { PageServerLoad } from './$types';

const CACHEABLE = 'public, s-maxage=86400, stale-while-revalidate=86400';

export const load: PageServerLoad = async ({ url, setHeaders }) => {
	const view = parseParams(url.searchParams);

	let industries: string[] = [];
	let loadError: string | null = null;
	try {
		industries = await getIndustries();
	} catch {
		loadError = 'The NYU data could not be loaded right now.';
	}

	if (industries.length > 0) {
		const known = view.selection.industries.filter((name) => industries.includes(name));
		const askedForSome = url.searchParams.getAll('i').some((v) => v !== '');
		view.selection.industries =
			known.length === 0 && askedForSome ? [...DEFAULT_SELECTION.industries] : known;
	}

	const { selection, layout } = view;
	const ready =
		selection.multiples.length > 0 && selection.regions.length > 0 && selection.industries.length > 0;

	if (loadError || !ready) {
		setHeaders({ 'cache-control': 'no-store' });
		return { view, industries, loadError, model: null, updated: null };
	}

	const comparison = await getComparison(selection);
	const partial = Object.keys(comparison.errors).length > 0;
	setHeaders({ 'cache-control': partial ? 'no-store' : CACHEABLE });

	return {
		view,
		industries,
		loadError: null,
		model: buildLayout(selection, layout, comparison),
		updated: comparison.updated
	};
};
```

```ts
import { describe, expect, it } from 'vitest';
import { MULTIPLES, REGIONS, type Family } from '../catalog';
import { fetchWorkbook, pickColumn, type WorkbookData } from './nyu';

// Fetches the real NYU files. Run with `npm run check:data`, e.g. each January.
const books = new Map<string, Promise<WorkbookData>>();
function load(family: Family, regionId: string): Promise<WorkbookData> {
	const key = `${family}:${regionId}`;
	if (!books.has(key)) books.set(key, fetchWorkbook(family, regionId));
	return books.get(key)!;
}

describe('live NYU data', () => {
	for (const region of REGIONS) {
		for (const multiple of MULTIPLES) {
			it(`${multiple.id} resolves for ${region.id}`, async () => {
				const workbook = await load(multiple.family, region.id);
				const column = pickColumn(workbook, multiple.column, multiple.group);
				const numeric = [...column.values()].filter((c) => c.value !== null).length;
				expect(numeric).toBeGreaterThanOrEqual(20);
				expect(column.has('Total Market')).toBe(true);
			});
		}
	}
});
```

````markdown
# my-svelte-app

A [SvelteKit](https://svelte.dev/docs/kit) app for comparing valuation multiples from the [NYU Stern](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/data.html) industry datasets. It is deployed on Vercel.

## What it does

Pick 1-4 multiples, 1-4 regions and 1-4 industries on the home page and the app draws grouped bar charts:

- **Multiples:** EV/EBITDA, EV/EBIT, P/E (trailing, forward, current), P/B, EV/Invested Capital, P/S, EV/Sales.
- **Regions:** US, Europe, Global, Japan, India, China, Emerging Markets, Australia/NZ/Canada.
- **Industries:** the 94 NYU industries plus the market-wide totals.

By default each multiple gets its own panel, industries run along the x axis and regions are the colours. The *Chart layout* dropdowns let you swap those roles. Bars based on fewer than 10 firms are hatched, missing values show as "n/a", and *Show data* lists the exact numbers.

Every selection is stored in the URL, so a view can be bookmarked or shared, for example `/?m=pe_trailing&m=pbv&r=us&r=europe&i=Steel&i=Total+Market`. Parameters: `m` multiples, `r` regions, `i` industry names (repeat a parameter for each value), and `p`, `x`, `c` for the panel, x-axis and colour roles.

## How it works

NYU publishes the data as legacy `.xls` workbooks, one per multiple family and region (32 files, updated about once a year). The server downloads only the files a view needs, parses them with [SheetJS](https://sheetjs.com), and keeps them in memory for 24 hours. Responses are cacheable by Vercel's CDN. If NYU is unreachable, a previously cached copy is served.
````
